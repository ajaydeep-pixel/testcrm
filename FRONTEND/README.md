# Frontend (React)

This folder will contain a React-based POS and admin interface.

Recommended quick start (create app with Vite or CRA):

```bash
cd FRONTEND
npx create-react-app .
# or using Vite: npm create vite@latest . --template react
```

Key UI pieces to implement:
- POS billing screen with barcode scanner support
- Product add/edit modal (instant-add during billing)
- Inventory management views
- Reports and analytics pages
