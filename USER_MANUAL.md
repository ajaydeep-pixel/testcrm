# User Manual

## Login
- Use admin or staff credentials to log in.

## Billing
- Scan barcode or search product.
- If product not found, add instantly.
- Add items to cart, apply discounts, and generate invoice.

## Inventory
- Track stock status (available, damaged, used, etc).
- Receive low stock alerts.
- Add inventory manually or via bulk upload.

## Purchases & Suppliers
- Create purchase orders.
- Manage supplier database.
- Auto-update stock after purchase.

## Reports
- View daily/monthly sales, profit/loss, stock aging, and more.

## Backup & Sync
- Local database for offline use.
- Cloud sync when online.

## Security
- Admin and staff roles.
- Activity logs for all actions.
